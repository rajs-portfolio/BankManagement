# 🏦 Bank Management System

A simple, menu-driven **Bank Management System built with Java** that simulates basic banking operations through a command-line interface (CLI). The application allows users to check their account balance, deposit money, and withdraw funds while ensuring basic transaction validation.

This project was developed as a hands-on learning experience to strengthen my Java programming fundamentals, improve problem-solving skills, and explore the practical implementation of basic Object-Oriented Programming (OOP) concepts.

## ✨ Features

- 💰 **Balance Inquiry** – Check the current account balance.
- ➕ **Deposit** – Add money to the account.
- ➖ **Withdrawal** – Withdraw money from the available balance.
- 🛡️ **Transaction Validation** – Prevent withdrawals that exceed the available balance.
- 🔄 **Interactive Menu** – Navigate through banking operations using a simple menu.
- 🚪 **Exit** – Exit the application gracefully.

## 🛠️ Tech Stack & Concepts

- **Java** – Used to develop the banking application.
- **Scanner** – Handles user input through the console.
- **Methods** – Organize functionality into reusable code blocks.
- **While Loop** – Keeps the application running until the user chooses to exit.
- **Switch-Case** – Handles menu selections and operation execution.
- **If-Else Statements** – Implement transaction conditions and validations.
- **Static Variables & Methods** – Manage account balance and shared functionality.
- **Basic OOP** – Apply foundational programming and object-oriented concepts.

## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### Prerequisites

- Java Development Kit (JDK) installed.
- A terminal or command-line interface.

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/BankManagementSystem.git
```

### 2. Navigate to the Project Directory

```bash
cd BankManagementSystem
```

### 3. Compile the Program

```bash
javac BankManagement.java
```

### 4. Run the Application

```bash
java BankManagement
```
